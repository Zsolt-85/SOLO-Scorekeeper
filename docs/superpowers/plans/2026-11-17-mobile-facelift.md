# Mobile-first interface facelift Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every SCORELOCK screen look deliberate on a phone (320–430px) with one shared layout system, without touching app logic, data or view markup structure.

**Architecture:** CSS-led facelift in `styles.css`, added as a final consolidated "mobile system" section that intentionally overrides the three historical makeup-pass blocks, plus `viewport-fit=cover` in `index.html`. Markup generated by `js/ui.js` stays as-is; selectors target existing classes/attributes (`.topbar`, `.topbar-links`, `.pr-row`, `.pr-who`, `.pr-den`, `.pr-row [data-action]`, `.board-row`, `.hero`, `.box-hero`, `.tiles`, `.podium`, `.view`, `#app`). No new dependencies or webfonts.

**Tech Stack:** Vanilla CSS with custom properties, existing system-font stack, node-based static server + browse (user's Chrome) for the visual sweep.

**Spec:** `docs/superpowers/specs/2026-11-17-mobile-facelift-design.md`

## Global Constraints

- Keep brand tokens exactly: `--bg #0d1020`, `--panel #171a30`, `--panel-2 #1f2340`, `--line #2b3054`, `--text #f2f3ff`, `--muted #9aa0c8`, `--gold #f0b429`, `--lose #ef7f6b`; system fonts only (no webfonts).
- No app-logic, storage, sync or view-markup changes. Only `styles.css` and the single viewport meta attribute in `index.html` are in scope.
- No horizontal scroll at 320/360/390/430px on any screen; no mid-word breaks or wrapped button labels; tap targets >=44px.
- Desktop >=901px (sidebar, 2-column lists) and tablet 768px (3-column shelf) must not regress.
- Visible keyboard focus and `prefers-reduced-motion` must remain respected.
- Screenshots of every verified route are the evidence for this plan (there are no DOM unit tests for CSS).

## Review Focus

- 320px with a long player name → name ellipsizes, no page-level horizontal scroll. Check: Task 2 sweep screenshot at 320px + `scrollWidth <= innerWidth`.
- Players row at 390px → name box no longer collapses to 35px; stats on one line; Edit/Remove on their own 44px row. Check: Task 1 computed-width assertion + Task 2 screenshot.
- Top bar with 4 buttons (Library page) → no two-line labels, no scattering. Check: Task 2 360px screenshot.
- Podium with 6+ players at 320px → bars wrap up to 3 per row, names ellipsized, no scroll. Check: Task 2 seeded local game screenshot.
- Desktop/tablet unchanged → sidebar shown >=901px, shelf 3 columns at 768px. Check: Task 3 768/1280px screenshots.

### Task 1: Shared mobile foundation

**Files:**
- Modify: `index.html` (viewport meta, line ~5)
- Modify: `styles.css` (append a final `/* MOBILE SYSTEM */` section)

**Interfaces:**
- Consumes: existing tokens and `.view`, `#app`, `.topbar`, `.topbar-links`, `.btn`, `.panel`, `.label`, `.muted`, `.hint` classes.
- Produces: global gutters, topbar behaviour and button rules that later per-screen overrides build on.

- [ ] **Step 1: Add the viewport attribute**

In `index.html`, change the viewport meta content from `width=device-width, initial-scale=1` to `width=device-width, initial-scale=1, viewport-fit=cover`.

- [ ] **Step 2: Write the foundation CSS**

Append to `styles.css` under a clear `/* MOBILE SYSTEM — foundation */` banner, in this order:

1. `:root` additions: `--gutter: 16px`, `--gap: 12px`.
2. Mobile reset (`@media (max-width: 900px)`): `body { padding: 0; }`, `#app { margin-left: 0; padding: var(--gutter) var(--gutter) calc(var(--gutter) + env(safe-area-inset-bottom)); padding-top: calc(var(--gutter) + env(safe-area-inset-top)); }`, `.view { max-width: none; padding-top: 1rem; }` — fixes the doubled 32px gutter that squeezes every card.
3. `.topbar { flex-wrap: nowrap; align-items: flex-start; }`, `.wordmark { white-space: nowrap; }`, `.tagline { max-width: 100%; }`, `.topbar-links { flex-wrap: nowrap; justify-content: flex-start; }`, and at `<=620px`: `.topbar { flex-direction: column; gap: 0.75rem; } .topbar-links { width: 100%; display: grid; grid-auto-flow: column; grid-auto-columns: minmax(0, 1fr); }`.
4. `.btn { white-space: nowrap; font-size: 0.9rem; padding-inline: 0.8rem; min-height: 44px; }` (keeps existing gold primary style).
5. `h1,h2,h3,.nm,.board-record,.pr-fav,.board-meta { overflow-wrap: normal; }` plus explicit ellipsis for `.nm` where used as a name (`.pr-who .nm`, `.board-row .who .nm`, `.tile-name`): `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`.
6. `:focus-visible` stays untouched; add nothing that removes outlines. Under `prefers-reduced-motion`, the existing blanket rule still applies.
